# 题库使用指南

## 选择练习范围

题库支持岗位、专题、公司和技术标签四类筛选条件，也支持搜索题目、公司、岗位和技术关键词。筛选条件会保存在页面地址中，复制地址即可保留当前练习范围。选择多个岗位时，题目满足其中任意一个岗位即可进入结果。

- 岗位筛选用于确定能力范围；
- 专题筛选用于确定知识范围；
- 公司筛选用于聚焦业务语境；
- 技术标签用于开展专项练习；
- 搜索框用于查找具体接口、器件或问题类型。

筛选完成后可以按列表顺序练习，也可以使用“随机练习”抽取当前范围内的题目。

## 完成一次练习

1. 打开题目后阅读问题与标签；
2. 暂停三十秒，在脑中组织回答；
3. 按照现象、根因、方案和验证进行表达；
4. 查看答案并切换岗位视角；
5. 选择“已掌握”“还模糊”或“需要复习”；
6. 进入下一题继续练习。

练习状态保存在当前浏览器中。题目打开后会生成包含题目标识的网址，可以复制网址分享或稍后继续阅读。

## 阅读不同岗位视角

同一个工程问题可能涉及硬件、FPGA、嵌入式 MCU 和嵌入式 Linux。答案页签会展示题目已经收录的岗位视角，可以帮助读者理解各岗位的关注重点与协作边界。

## 安排复习节奏

建议按照以下节奏循环练习：

- 当天：完成新题并记录遗漏内容；
- 次日：脱离答案重新回答；
- 一周后：随机抽取同类题目复习；
- 面试前：按照目标岗位与公司完成连续模拟问答。

::: tip 复习建议
优先复习标记为“需要复习”的题目，再检查“还模糊”的题目。需要记录完整回答时，可以保存题目网址，并记录首次回答、遗漏知识、正确结构和复习日期。
:::
