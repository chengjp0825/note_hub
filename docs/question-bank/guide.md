# 题库使用指南

## 选择练习范围

题库支持岗位、公司和技术标签三类筛选条件，也支持搜索公司、岗位和技术关键词。筛选条件会保存在页面地址中，复制地址即可保留当前练习范围。

- 岗位筛选用于确定能力范围；
- 公司筛选用于聚焦业务语境；
- 技术标签用于开展专项练习；
- 搜索框用于查找具体接口、器件或问题类型。

## 完成一次练习

1. 打开题目后阅读问题与标签；
2. 暂停三十秒，在脑中组织回答；
3. 按照现象、根因、方案和验证进行表达；
4. 查看答案并切换岗位视角；
5. 记录遗漏的知识点与验证方法。

## 阅读不同岗位视角

同一个工程问题可能涉及硬件、FPGA、嵌入式 MCU 和嵌入式 Linux。答案页签会展示题目已经收录的岗位视角，可以帮助读者理解各岗位的关注重点与协作边界。

## 安排复习节奏

建议按照以下节奏循环练习：

- 当天：完成新题并记录遗漏内容；
- 次日：脱离答案重新回答；
- 一周后：随机抽取同类题目复习；
- 面试前：按照目标岗位与公司完成连续模拟问答。

::: tip 记录模板
每道错题可以记录五项内容：题目、首次回答、遗漏知识、正确结构、复习日期。记录应当保留自己的表达，方便观察回答质量的变化。
:::
