# 面试准备

## 阅读岗位说明

先提取岗位说明中的四类信息：主要职责、必备技能、业务场景和经验要求。将每项要求映射到自己的项目、课程或实践经历，并记录可以证明能力的具体事实。

## 梳理项目经历

每个重点项目建议准备以下内容：

1. 项目解决的问题和关键指标；
2. 自己承担的模块和工作边界；
3. 采用的器件、接口、算法或系统方案；
4. 遇到的主要故障及其定位过程；
5. 测试方法、测量数据和最终结果；
6. 复盘后形成的工程经验。

::: warning 表达要求
涉及团队成果时，需要准确说明个人贡献。涉及性能提升时，需要提供测试条件、对照基准和测量结果。
:::

## 建立复习清单

按照目标岗位建立三层清单：

- 基础知识：概念、原理、公式和常见边界条件；
- 工程应用：选型、设计、实现、测试和调试；
- 项目追问：决策依据、异常处理、数据验证和改进方向。

可以从[岗位介绍](/question-bank/roles)确定能力范围，再使用题库的公司与技术标签缩小练习范围。

## 进行主动回忆

选择一道题目后，先用三十秒整理结构，再用两到三分钟完整回答。回答完成后查看解析，检查以下内容：

- 是否先说明场景和约束；
- 是否给出判断依据；
- 是否包含实施步骤；
- 是否说明验证方法；
- 是否覆盖异常情况和安全边界。

## 完成模拟面试

模拟面试应当保持连续问答，重点记录回答中出现的概念遗漏、数据含糊和逻辑中断。练习结束后，将问题加入复习清单，并在下一轮练习中再次回答。
